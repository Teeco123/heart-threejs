# Heart Threejs

3D model of a heart with ASCII filter made with threejs

## Demo

![](https://github.com/Teeco123/heart-threejs/blob/main/demo.gif)

## Running locally

Clone the project
```bash
  git clone https://github.com/Teeco123/heart-threejs
```

Go to the project director
```bash
  cd heart-threejs
```

Install dependencies
```bash
  npm install
```

Start dev server
```bash
  npx vite
```
